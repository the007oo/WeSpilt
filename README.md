# WeSplit

WeSplit is a simple check-splitting app built with **SwiftUI**.  
The idea is straightforward: after eating at a restaurant, you can enter the cost of your food, select the tip percentage, choose the number of people in your group, and the app will calculate how much each person should pay.

This project is part of my SwiftUI learning journey, following [Hacking with Swift](https://www.hackingwithswift.com) tutorials.

---

## 🚀 Features

- Enter the total cost of the bill  
- Choose a tip percentage  
- Select how many people to split with  
- Instantly see how much each person owes  

---

## 🎯 Purpose

The goal of this project isn’t just to build an app—it’s to learn the **fundamentals of SwiftUI**, including:

- UI design basics  
- Working with text fields, pickers, and forms  
- Managing app state with `@State`  
- Combining views and logic into a functioning app  

---

## 📚 Learning Structure

The project is broken down into three parts:

1. **Hands-on introduction** – learning individual SwiftUI components in isolation.  
2. **Step-by-step guide** – applying those components in the actual app.  
3. **Challenges** – extra exercises to expand the project independently.
